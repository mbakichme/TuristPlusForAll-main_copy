## Konvencije

- Obračun: `calc_ugovor_values` (EUR) / `calc_ugovor_d_values` (din) u routes.py; kurs kurs.resenje.org `exchange_middle`, keš `EUR_RATE_CACHE`

- Beskonačna skrola: IntersectionObserver (600px) + requestId guard + BATCH 100, debounce 400ms

## Rezervacije (RezervacijePage) — Sačuvaj/Izmeni (gotovo)
- Backend: `POST /rezervacije` (novi) + `PUT /rezervacije/{kljuc}` (izmena); modeli `RezervacijaIn/RezPutnikIn/RezBoravakIn/RezCeneIn/RezCenaRedIn` u routes.py
- Numeracija: MAX(broj) **unutar godine iz datumod** + 1 (reset godišnje → 1/27); sufix = god(datumod) YY; kontrole: advisory lock `REZ_ADVISORY_LOCK = 9_250_000_000_001` + UNIQUE(kljuc) + retry 6× na IntegrityError (import path)
- Mapiranje: naziv smeštaja→`naziv`, mesto→`mesto`, destinacija→`destinacija` (NAZIVI, ne ID), soba→`soba` (broj), struktura→`apartman`, email→`refno`, `datumoddo` = `DD.MM.YYYY-DD.MM.YYYY` (bez razmaka), `obradio` = user first+last, `danas` = belgrade now (samo POST), timelimit samo za Predrezervaciju
- Cena prevoza po nosiocu: RT → `cenart/kolrt`+`cenadrt`, inače `cenaow/kolow`+`cenadow`; nekorišćena strana kol=1, cena=0 (kao legacy)
- Popust/provizija: procenat direktno (popustar/popustpr/procenatar); iznos → % osnove (EUR iznos ÷ bruto EUR, RSD ÷ bruto RSD); **procenatpr = IZNOS PO OSOBI** (iznos ÷ količina iste valute) — legacy calc: provizija prevoza = procenatpr × kol
- Saputnici → `aranzman_dopuna` (delete+reinsert pri PUT); uzrast/viza se NASLEĐUJU po imenu (form ih ne unosi); `ulazak` se čuva; email saputnika u dopuna.email
- Frontend: `zakljucano = izabraniUgovor && !izmena`; dugme: Sačuvaj(POST) → Izmeni(otključava) → Sačuvaj(PUT) → reload kroz izaberiUgovor → zaključano; pretraga NIKAD zaključana; Uplate tab NIKAD zaključan; svi inputi u Aranžman/Obračun/Prevoz `disabled={zakljucano}`; Chk/EmailInput/SmerSelect/DatumField/ProcenatRed imaju `disabled` prop
- `CUVAR = "__cuvano__"` sentinel: sačuvani nazivi van referentnih lista (stari ugovori) → SelectItem "(sačuvano)" + payload fallback `smestajNaziv/sobaBroj/mestoNaziv/destinacijaNaziv` (backend: ID pobeđuje, inače fallback) — sprečava gubitak podataka pri čuvanju
- `tipOpcije`: nepoznat tiprezervacije iz baze se dodaje u Select (bez prepisivanja pri čuvanju); struktura se učitava iz `apartman`
- Auto-bind destinacije za mesto (Prevoz tab) pauziran dok se mesto učitanog ugovora NE promeni (`mestoUgovoraRef`) — ne pregazi sačuvani destinacija
- NISU čuvana (nemaju kolone u bazi): osiguranje čekboks putnika, promena strukture, mesto sedenja, plaćeno/želja, datumi OW/RT po putniku, destinacije polaska/povratka po putniku, SP flag; `poslovnica` ostaje NULL
- Test: `test_rezervacije_api.py` (dev 3158; kreira 34114/26, proverava round-trip, briše za sobom)
- **Zauzeće termina (sudar)**: `_rez_proveri_konflikt` u routes.py (zvan iz `rezervacija_vrednosti`, POST i PUT) — isti smeštaj (`naziv`) + ista soba (`TRIM(COALESCE(soba,''))`) + overlap `datumod < :do AND datumdo > :od` (ista konvencija kao /slobodne-sobe — naslonjeni boravak na dan odjave je dozvoljen); 409 "Termin je zauzet — soba X (...) već ima zapis u periodu ...: ugovor K (putnik)"; PUT prosleđuje `exclude_kljuc` (izuzima sebe); check se preskače ako smeštaj ili soba nisu poznati; frontend `sacuvajRezervaciju` catch: poruka sadrži "zauzet" → toast 12s sa opisom. Test: `test_rezervacija_konflikt.py` (blokada upisa, naslonjeni, self-exclusion, druga soba; briše za sobom)
